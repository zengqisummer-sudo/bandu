# 已确认决策

- 需求已在对话中确认，用户已授权开始实现，不重复设置文档审批门。
- 保留前端视觉，以用户最后确定的虚线注释/高亮想法规则为准。
- 章节可总结本章结论；全书导读不发送原文，须实际搜索。
- 独立注释优先于同词共享注释。深挖不迁移、不删除历史文件。
- 不新增测试集，用户直接验收；只做必要静态检查和构建。

## 想法卡修订

用户最新要求覆盖此前“话题=Markdown 标签”的决定；话题为独立概念。本书列表与跨书关联展示分开。默认多话题选择其中一个建立关联，卡片时间采用原 createdAt，不因编辑重置。

## 想法卡追加与快捷操作

- 话题索引随亮暗主题切换配色；堆叠底边可直接展开关联卡片，无关联时菜单隐藏“查看链接”。
- 右上角铅笔复用编辑入口；加号在同一卡片、同一原文下追加想法，不新增独立卡片。每条追加内容独立记录创建时间，用分隔线展示，编辑不重置时间。
- 追加内容保存在 Annotation/ChatSession 的可选 entries 字段，旧卡片无需迁移；编辑入口可修改追加内容，链接搜索涵盖追加内容。Markdown 继续只追加历史。
