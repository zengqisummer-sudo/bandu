# 实现顺序

1. 数据与存档：注释、话题、对话锚点、联网导读。
2. 正文标记：注释与想法独立、悬停与点击、全文同步。
3. 侧边栏：导读、注释编辑/查找、跨书想法卡、摘录定位与返回。
4. 设置与文档：可编辑 prompt、联网配置；类型检查及正式构建。

人工验收：重叠注释/想法；相同词跨章同步与独立例外；多话题跨书分组；完整会话保存；搜索切换；跨章跳转返回；重启后恢复；联网失败提示。

## 交付状态（2026-09-28）

以上实现已完成；TypeScript 检查与 npm run build 通过，dist 已更新。未新增测试集，未做浏览器端到端或真实模型调用验收。构建存在 CSS Custom Highlight 伪元素识别告警与大包提示，不影响构建产物生成。

手动验收建议按以下顺序：
1. 对整句写想法，对句内人名写注释：高亮与虚线叠加；悬停看注释，点词定位注释卡，点句子其他区域或星号定位想法卡。
2. 先建独立注释，再对同词另一处开启同步全文；跨章查看，原独立解释保留，其他位置共用一张卡；修改共享卡后各处同步。
3. 问AI进行两轮以上对话，折叠再展开；关联两个 #话题；另一书使用相同话题后确认分组；重启检查内容。
4. 点击想法/摘录卡跳原文，点击右下返回阅读进度；切换章节重复检查。
5. 注释查找切换原文/注释；生成章节导读；配置联网模型后生成带来源的全书导读。
